# The Water Way

This is a mobile-first browser game built with Vite and vanilla JavaScript.

## Run in development

Use the **Start application** workflow. It runs:

```sh
npm run dev -- --host 0.0.0.0 --port 5000
```

## Build for publishing

The app is configured as a static deployment:

```sh
npm run build
```

Replit publishes the generated `dist` directory.
